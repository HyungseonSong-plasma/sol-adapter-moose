## Numerical V&V track

### Predeclared benchmark

Canonical thermal slice:

- steady 1-D heat equation;
- constant conductivity `k = 45 W/(m K)`;
- domain `x in [0, 1 m]`;
- Dirichlet condition `T(0) = 400 K`;
- no canonical right-wall boundary condition, therefore the realized MOOSE problem uses its natural zero-flux boundary at `x = 1 m`;
- no volumetric source.

The analytical solution is:

```text
T(x) = 400 K
```

for the full domain.

### Metric and fixed tolerance

V&V observes backend-native nodal extrema:

```text
T_min
T_max
```

The metric is:

```text
max(|T_min - 400 K|, |T_max - 400 K|)
```

Acceptance is fixed at:

```text
<= 1e-8 K
```

This tolerance was accepted before running Phase 5 numerical evidence and must not be relaxed merely to turn a failing result green. The constant solution is exactly representable in the A0.1 first-order Lagrange space; the tolerance therefore permits numerical roundoff/solver effects rather than discretization error.

### Backend-owned instrumentation only

`tests/phase5_thermal_vv.rs` starts from the normal adapter-generated thermal input and adds test-only MOOSE instrumentation:

- `NodalExtremeValue` for nodal maximum;
- `NodalExtremeValue` for nodal minimum;
- CSV output for machine-readable extraction.

This follows public MOOSE postprocessor/output behavior. The instrumentation is not added to the production adapter IR/serializer and creates no SOL 0.3 `ObservationResult`, `DatasetManifest`, or canonical result semantics.

The CI-only numerical record is `target/phase5-vv-evidence/thermal-vv.json`.
